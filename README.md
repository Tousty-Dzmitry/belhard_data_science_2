При написании работ используется python 3.10.0.

Homework 1.1: исползуется набор данных рукописных цифр (MNIST), модель классификации для распознования цифр - tensorflow.

homework 1.2: используются данные о пассажирах самолета, модель классификации предсказывает класс обслуживания.

homework 2.1: решение задачи класстеризации.

homework 2.2: вариационный автоэнкодер для генерации новых изображений лиц: Реализация вариационного автоэнкодера (VAE).

AI_agent: создание простого ИИ-агента для навигации по сетке 5x5, где нужно собрать сокровища (T) и избежать ловушек (X).

Сhatbot: чат-бот, который по названию блюда возвращает его состав, используя заранее подготовленный словарь.

Results_pytorch-CycleGAN-and-pix2pix: генерация фотореалистичных изображений по эскизам рисунков (CycleGAN, pix2pix).

drone-detection-1: в работе используется YOLOv8n обученная для распознования дронов на видеозаписях.
